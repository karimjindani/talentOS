## Notes

- The `engineering_journal_entries` unique constraint on `(tenantId, applicantId, missionId, entryDate)` was dropped via migration `20260824000000_feature_flags_and_journal_testing`. Production integrity for one-per-mission-per-date is now enforced by the application-layer `assertEntryDateAvailable` check in `journal.ts` (active when the flag is off).
- The `FeatureFlag` table is global (not tenant-scoped). Flags apply across all tenants.
- The ops console flags API requires the same Keycloak session as all other ops endpoints (SUPER_ADMIN or ORG_ADMIN).
- Manual testing was performed against the running Docker container on `localhost:3100` (applicant) and `localhost:3300` (ops).
