## Notes

- **The one skip is pre-existing and documented**: `storage: Storage browser upload/download scenario`,
  carried forward since `v0.18.3`. The runner exits 0 for skips, so it does not fail the job.
- **Two CI-only capture defects were fixed inside this iteration**, both exposed only once
  `e2e-evidence` began running the capture against a fresh seeded database rather than a developer's
  dev database: `seed-dashboard.ts` created a `ProgramTask` without the `missionId` that `v0.20.0` made
  required, and the workflow screenshots targeted a user that does not exist in a clean seed. A third
  change makes Ops-console shots skip gracefully when that console is unreachable.
- **This iteration shipped without its plan/test-results pair**, which is why both documents are dated
  `2026-08-13` and were written during `v0.20.2`. The `D-096` identifier collision merged in the same
  window; both are recorded in `D-102`.
- **Request logging shipped unconditional** and is corrected in `v0.20.2` (`D-102`).
