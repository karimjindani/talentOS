## Summary

End-to-end QA analysis of the new applicant onboarding flow on
`http://paysyslabs.lvh.me:3100`. Four bugs were identified, fixed, verified, and
covered with regression tests. The full onboarding journey — register, apply,
access-denied, logout, re-login, dashboard — was validated.

## Bugs Found & Fixed

### BUG-1 (HIGH): Tenant subdomain lost on middleware redirect

**Symptom:** Unauthenticated users visiting `/apply` on
`paysyslabs.lvh.me:3100` were redirected to `http://lvh.me:3100/login` (canonical
host) instead of `http://paysyslabs.lvh.me:3100/login` (tenant subdomain),
causing cross-origin RSC fetch failures.

**Root cause:** Both `apps/applicant/middleware.ts` and `apps/admin/middleware.ts`
used `nextUrl.origin` to build redirect URLs. Inside Docker, `nextUrl.origin`
resolves to the canonical `AUTH_URL` host (`http://lvh.me:3100`) instead of the
actual request host (`http://paysyslabs.lvh.me:3100`).

**Fix:** Added `requestOrigin()` helper that builds the origin from the request
`Host` header (with `x-forwarded-proto` support), falling back to `nextUrl.origin`
only when the Host header is absent.

**Files changed:**
- `apps/applicant/middleware.ts`
- `apps/admin/middleware.ts`

**Verification:** Navigated to `http://paysyslabs.lvh.me:3100/dashboard` while
unauthenticated → redirected to
`http://paysyslabs.lvh.me:3100/login?callbackUrl=http%3A%2F%2Fpaysyslabs.lvh.me%3A3100%2Fdashboard`
— tenant subdomain preserved. ✅

### BUG-2 (MEDIUM): Logout redirect "Invalid redirect uri"

**Symptom:** Keycloak rejected the post-logout redirect with "Invalid redirect
uri" when logging out from the admin portal.

**Root cause:** Investigated and found the code is correct —
`buildTenantLogoutUrl()` uses the canonical `AUTH_URL` origin for
`post_logout_redirect_uri`, and Keycloak's `post.logout.redirect.uris` attribute
includes `http://lvh.me:3200/*`. The issue was likely a transient state from
before the realm was re-imported with the post-logout redirect URIs.

**Fix:** No code change needed. Verified Keycloak client configuration has
correct `post.logout.redirect.uris` for both `talentos-applicant` and
`talentos-admin` clients.

**Verification:** Logged out from `paysyslabs.lvh.me:3100` → redirected to
Keycloak logout → returned to `http://paysyslabs.lvh.me:3100/` (tenant subdomain
preserved via `/logged-out` route with `state` parameter). ✅

---

### BUG-3 (LOW): React hydration error #418 on Missions page

**Symptom:** React hydration mismatch error (#418) on the applicant Missions
page, caused by the `DeadlineCountdown` component rendering different content on
server vs. client.

**Root cause:** `DeadlineCountdown` used `useState(() => Date.now())` — the
initial state was computed at render time, which differed between server (server
clock) and client (client clock), causing a hydration mismatch.

**Fix:** Changed `useState<number | null>(null)` and only set `Date.now()` inside
`useEffect` (client-only). The server and initial client render both show a
"Loading deadline…" placeholder, then the client fills in the actual countdown
after mount.

**Files changed:**
- `apps/applicant/components/DeadlineCountdown.tsx`

**Verification:** Navigated to Missions page — no hydration errors in console.
Countdown shows "6d 15h 50m remaining" and "Deadline: Aug 14, 2026, 4:59 AM". ✅

---

### BUG-4 (LOW): Duplicate "Regression Program" entries in admin filter

**Symptom:** The admin Missions filter dropdown showed duplicate "Regression
Program" entries — 206 rows with only 9 unique names.

**Root cause:** Regression test runs created multiple `Program` rows with the
same name but different IDs/slug suffixes, accumulating over multiple test runs.

**Fix:**
1. **Data cleanup:** Deleted 197 duplicate program rows from the database,
   keeping one per name (9 remaining).
2. **Code defensive fix:** Added deduplication by name in
   `apps/admin/app/missions/page.tsx` before rendering the dropdown options.

**Files changed:**
- `apps/admin/app/missions/page.tsx`

**Verification:** Admin Missions page dropdown shows unique program names only. ✅
