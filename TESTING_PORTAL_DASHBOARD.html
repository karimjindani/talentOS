⌨️ Useful Commands

Testing Flow for Graduate Portal

  • 1. Visit: /graduates - See directory of all public profiles
  • 2. Search and filter to find graduates
  • 3. Click on a graduate to view their public profile
  • 4. Submit recruiter access request with email
  • 5. Check email inbox for verification link
  • 6. Click verification link to access full portfolio
  • 7. Login as applicant to /dashboard
  • 8. Complete all missions to see consent modal
  • 9. Click "Publish Profile" in consent modal
  • 10. Fill out graduate profile form with bio/links
  • 11. Verify profile appears in /graduates directory
  • 12. View your published profile from the directory

Docker & Logs

  • docker-compose logs -f - View all logs
  • docker-compose logs -f applicant - Applicant portal logs
  • docker-compose logs -f admin - Admin portal logs
  • docker-compose logs -f keycloak - Keycloak logs
  • docker-compose ps - List all running services
  • docker-compose restart - Restart all services

Regression Tests

  • npm.cmd run regression:applicant - Test applicant flows
  • npm.cmd run regression:admin - Test admin flows
  • npm.cmd run regression:auth - Test authentication
  • npm.cmd run regression:missions - Test missions
  • npm.cmd run regression:all - Run all tests
